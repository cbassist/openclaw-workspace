# Skill: Honest Self-Evaluation Under Null Results

## When to Use
When asked to evaluate or reflect on work that was not completed.

## Procedure

1. **Acknowledge the null state explicitly** — never fabricate progress or results.
2. **Evaluate what DID happen** — planning, task decomposition, tool setup — even if execution didn't follow.
3. **Score honestly** — 0 is a valid score. N/A is valid when a dimension can't be measured.
4. **Diagnose WHY nothing happened** — this is the most valuable output of a null reflection.
5. **Extract forward-looking value** — what would need to change for the next attempt to succeed?

## Anti-Patterns
- Inflating scores because "the plan was good"
- Treating planning artifacts as execution evidence
- Skipping the reflection because "there's nothing to reflect on"
- Fabricating hypothetical outcomes

## Key Principle
A reflection that honestly says "nothing happened and here's why" is more valuable than one that pretends partial work occurred.
